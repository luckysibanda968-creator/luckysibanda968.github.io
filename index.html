    CITY OF BULAWAYO

    About this map

    A practical starting point for discovering public and civic places across Bulawayo.

    How to use the map

    • Search by facility name, stand number or suburb, or choose a category to filter results.
    • Select a marker to see parcel details. Zoom in to inspect facility boundaries.
    • Use the layer and basemap controls to change the map context. Measure tools work by placing points on the map.
    • Download the filtered results as GeoJSON or CSV, or print the current map view.

    Data sources & limitations

    Parcel geometries and land-use labels come from the cadastral files supplied with this project. Facility categories are inferred from land-use and name text. The source does not consistently identify City Council ownership, ward boundaries, opening hours, contacts or operational status. These details should be verified before use.

    Basemaps: OpenStreetMap contributors, CARTO and Esri. Map rendering: Leaflet and Leaflet plugins.
